# TimeTrack

Toggl Track ライクな時間記録アプリ。ブラウザ単体で動作し、外部ネットワークへの接続は一切不要。

## 特徴

- **単一HTMLファイル** - ビルド不要、`index.html` をブラウザで開くだけで使える
- **外部依存ゼロ** - CDN・外部API を使用しない完全オフライン動作
- **ローカルフォルダ保存** - File System Access API でデータを JSON ファイルとして保存
- **ダークテーマ** - Toggl Track 風のデザイン

## 使い方

### 起動

`index.html` をブラウザで開く。

```sh
open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
```

### 基本操作

1. **保存先フォルダを選択** - ヘッダーの「保存先フォルダ選択」ボタンからデータの保存先を指定
2. **タイマー計測** - タスク名を入力し、プロジェクトを選択して再生ボタンをクリック（Enter キーでも開始可能）
3. **手動追加** - タイムラインビューの「+ 手動追加」から開始・終了時刻を指定して記録
4. **集計確認** - 「集計」タブでプロジェクト別・タスク別の合計時間を確認。日付フィルタで期間を絞り込み可能

### データ保存

| ブラウザ | 保存方式 |
|---------|---------|
| Chrome / Edge | File System Access API で選択フォルダに `data.json` を自動保存 |
| Firefox / Safari | localStorage に保存。JSON ファイルのエクスポート/インポートで持ち出し可能 |

## 機能一覧

- タイマースタート / ストップ
- プロジェクト管理（名前・カラー設定）
  - アーカイブ / 解除（アーカイブ済みプロジェクトへの新規計上不可。過去データは引き続き表示）
- タスク名入力
- タイムエントリの編集・削除
- 手動エントリ追加
- 日付別タイムライン表示
- 集計ビュー（プロジェクト別・タスク別）
  - 日付フィルタ（今日 / 昨日 / 今週 / カスタム範囲）
  - プロジェクト内タスク内訳の展開表示
- データの自動保存（変更後 500ms）
